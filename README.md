# qa-service

### Технические моменты 
- По ТЗ необходимо обрабатывать динамические параметры, однако встроенный
мультиплексор так не умеет. Поэтому мой выбор пал на `go-chi`, который совместим с `net/http`.

- Миграции применяются автоматически при запуске сервиса.

### Сборка

#### Локально (без Docker)
```bash
make run
```

По умолчанию используется конфиг `config/config.toml`. При необходимости можно указать путь:

```bash
make run CONFIG_PATH=path/to/config.toml
```

#### Через Docker Compose

```bash
make docker-up
```

Останавливаем контейнеры:

```bash
make docker-down
```

#### Тесты

```bash
make test
```

### Swagger UI

После запуска сервиса документация доступна по адресу [http://localhost:8080/docs](http://localhost:8080/docs).
